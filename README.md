# Hodi Fellows

**Build real work. Show it in public.**

Hodi Fellows is a free, six-week programme for university and college students who can code a little and want real experience. Fellows work in peer groups of five, learn Git and code review, contribute to real open-source projects, and leave with a public portfolio.

## Start here

- 🌐 **Website:** [hodifellows.com](https://hodifellows.com)
- 👋 **Meet the fellows:** [hodifellows.com/fellows](https://hodifellows.com/fellows/)
- 🛠️ **Fellows' project:** [hodifellows/fellows](https://github.com/hodifellows/fellows), the fellows page, built by the fellows

## For fellows

1. Accept your invitation to this organisation.
2. Read [CONTRIBUTING.md](https://github.com/hodifellows/fellows/blob/main/CONTRIBUTING.md).
3. Open your **"Add myself to the fellows page"** issue and make your first pull request.

## How we work

Every change goes through an issue, a branch, a pull request and a review. We review code, not people, and we explain our work in our own words. See our [Code of Conduct](https://github.com/hodifellows/fellows/blob/main/CODE_OF_CONDUCT.md).
